# 解析アルゴリズム

実装は `src/lib/analysis/analyze.ts`。React、DOM、現在時刻、乱数に依存しない純粋関数です。同じ入力・設定は同じ区間と統計を返します。しきい値は理由付きの `config.ts` に集約し、`analyzeTrack(track, overrides)` で変更できます。

## 入力と境界

`fast-xml-parser` でXML構文を検証し、名前空間付きGPX、複数の `trk / trkseg` を読み込みます。`wpt` と `rte` は対象外。DOCTYPE/ENTITYを拒否し、15MB・15万地点までに制限します。
緯度経度の範囲を検証し、不正座標の前後は接続しません。標高と時刻は欠損を `null` として保持。タイムゾーンのない時刻も欠損扱いです。順序の並べ替えや時刻の補完は行いません。

## 水平距離と速度

- 球半径6,371,008.8mのHaversine距離。3D斜距離ではありません。
- 速度 = 水平距離 / 実経過秒。表示時に3.6倍してkm/hに変換。
- 162km/h超の移動は非接続。単一地点の前後が「90km/h以上、周辺速度中央値の3倍超、または162km/h超」で、前後を直接結んだ速度が妥当なら、その地点を除外します。
- 120秒超の空白、重複／逆転時刻、セグメント切断では距離・速度を加算しません。異常な移動の後は新しい連続ブロックを開始します。
- 時刻が欠損した辺は500m以下なら距離のみ採用し、速度・時間は未算出。500m超なら接続しません。

最高速度はこの検証を通った全移動の速度です。滑走別の最高速度はその滑走に属する辺のみが対象です。無検証の生データ最高速度は使用しません。

## 標高ノイズと累積標高差

連続ブロック内で前後2点を含む5点の中央値を採用します。端点は元の標高を保持。欠損標高は埋めません。
累積値の基準標高との差が6mに達するまで加算を保留し、達したとき差分を上昇／下降へ加算して基準を更新します。微小な往復をすべて足す方式と比べ、±2m程度のノイズを過大計上しません。単調な斜面で最後に残る6m未満は切り捨てます。欠損や切断をまたいだ標高差は加算しません。

この方式は小さな起伏を過小評価し、大きく緩やかなGPSの標高ドリフトを完全には除去しません。端点外れ値、長期ドリフト、誤ったジオイド補正は既知の制約です。

## 状態の推定

各辺について、実時間±20秒以内の周辺標高から標高変化率を求めます。

| 状態 | 基本条件                               |
| ---- | -------------------------------------- |
| 停止 | 水平速度 < 0.7m/s（約2.5km/h）         |
| 上昇 | 移動中、標高変化率 ≥ +0.08m/s          |
| 滑走 | 水平速度 ≥ 2m/s、標高変化率 ≤ −0.08m/s |
| 不明 | 上記以外、または時刻／標高の根拠が不足 |

滑走中は0.9m/sまで減速しても標高変化率が+0.02m/s未満なら判定を継続します（低速折り返し用のヒステリシス）。同じ状態に挟まれた15秒未満の上昇／下降の反転を抑えます。欠損を不明から滑走へ書き換える処理はありません。
停止判定は標高なしでも可能です。移動中の標高欠損は不明。リフトと徒歩、スキーとスノーボードは区別できません。

## 滑走区間と集計の整合性

連続した滑走辺をまとめ、25秒以内の停止のみを挟む場合は同一滑走にします。停止辺は停止のまま保持し、滑走時間・距離には加算しません。
30秒以上、水平100m以上、下降8m以上を満たす区間を1本とします。満たさない滑走候補は不明へ戻し、全体だけに滑走距離が残ることを防ぎます。

- 全体の滑走距離・滑走時間は、採用した滑走別の値の厳密な合計。
- 平均滑走速度 = 全滑走距離 / 全滑走時間。各滑走の速度の単純平均ではありません。
- 滑走の開始〜終了は短い停止を含みます。表の滑走時間は停止を除きます。
- 総移動距離、累積上昇／下降、最高速度、標高範囲は全移動が対象。滑走別の下降を合計しても全移動の累積下降と一致するとは限りません。
- 判定不能な時間には同一セグメント内の大きな記録空白を含みます。異なるセグメント間の時間は加算しません。時刻欠損部分の長さは推測しません。

## 描画と処理量

解析はWeb Workerで実行し、再インポート時は前の処理を中断します。解析自体は全地点を使用します。地図はCanvas描画と状態・色ごとの連続パスにまとめ、長いパスを間引きます。グラフは約1,400点を目安に間引き、状態境界・滑走境界・切断を優先して保持します。線形に近い時間とメモリを使いますが、極端に頻繁な状態変化は描画パス数を増やします。

欠損・切断はグラフで線を切ります。時刻がない部分は地図で確認できます。選択地点はグラフ、地図、キーボード操作可能なスライダーで共有します。図の間引きは統計に影響しません。

## 合成サンプル

`public/samples/hakuba-synthetic.gpx` は架空の4本の滑走・3回の上昇、山麓と山頂の休憩、滑走中2回の15秒停止を含みます。座標は白馬付近ですが実在コースを表しません。標高は概ね1,280〜1,840m、5秒間隔。実走行データを同梱していません。

テストの直線斜面では、61地点・5秒間隔・緯度0.0003度刻み・1点3m下降から、300秒・約2,001.5m・180m下降・平均約24.02km/hの1本を期待します。±2mの平坦ノイズ600区間では累積上下とも0mを期待します。その他の期待値は `src/tests/analysis.test.ts` に明記しています。
