# 解析アルゴリズム

実装は `src/lib/analysis/analyze.ts`。React、DOM、現在時刻、乱数に依存しない純粋関数です。同じ入力・設定は同じ区間と統計を返します。しきい値は理由付きの `config.ts` に集約し、`analyzeTrack(track, overrides)` で変更できます。

## 入力と境界

`fast-xml-parser` でXML構文を検証し、名前空間付きGPX、複数の `trk / trkseg` を読み込みます。`wpt` と `rte` は対象外。DOCTYPE/ENTITYを拒否し、15MB・15万地点までに制限します。
緯度経度の範囲を検証し、不正座標の前後は接続しません。標高と時刻は欠損を `null` として保持。タイムゾーンのない時刻も欠損扱いです。順序の並べ替えや時刻の補完は行いません。

## 水平距離と速度

- 球半径6,371,008.8mのHaversine距離。3D斜距離ではありません。
- 速度 = 水平距離 / 実経過秒。表示時に3.6倍してkm/hに変換。
- 同一セグメント内で直前地点と時刻が完全に同一かつ水平距離が2m以内の冗長ポイントは、軌跡を分断せずに除外します。片方にだけ標高があるときは、その実測地点を残します。2m超の移動を伴う重複時刻や逆転時刻は異常時刻として非接続にします。
- 162km/h超の移動は非接続。単一地点の前後が「90km/h以上、周辺速度中央値の3倍超、または162km/h超」で、前後を直接結んだ速度が妥当なら、その地点を除外します。
- 120秒超の空白、重複（2m超移動）／逆転時刻、セグメント切断では距離・速度を加算しません。異常な移動の後は新しい連続ブロックを開始します。
- 時刻が欠損した辺は500m以下なら距離のみ採用し、速度・時間は未算出。500m超なら接続しません。

最高速度はこの検証を通った全移動の速度です。滑走別の最高速度はその滑走に属する辺のみが対象です。無検証の生データ最高速度は使用しません。

## 標高ノイズと累積標高差

連続ブロック内で前後±6秒以内の標高中央値を採用します。時刻が連続する範囲では最低前後1点を取り、時刻のない点は前後2点を使用します。偶数点の中央値は中央2値の平均です。連続ブロックの端点は元の標高を保持し、欠損標高は埋めません。高密度の時間窓では等間隔に間引き、最大61点程度で中央値を算出します。
累積値の基準標高との差が6mに達するまで加算を保留し、達したとき差分を上昇／下降へ加算して基準を更新します。微小な往復をすべて足す方式と比べ、±2m程度のノイズを過大計上しません。単調な斜面で最後に残る6m未満は切り捨てます。欠損や切断をまたいだ標高差は加算しません。

この方式は小さな起伏を過小評価し、大きく緩やかなGPSの標高ドリフトを完全には除去しません。端点外れ値、長期ドリフト、誤ったジオイド補正は既知の制約です。

## 状態の推定

各移動辺について、停止・時刻欠損をまたがない範囲で、移動辺の始点の10秒前から終点の10秒後までの有効標高に最小二乗線形回帰を適用し、標高変化率（m/s）を求めます。高密度の時間窓では等間隔に間引き、対象辺の両端を必ず使用します。

| 状態 | 基本条件                                 |
| ---- | ---------------------------------------- |
| 停止 | 水平速度 < 0.7m/s（約2.5km/h）           |
| 上昇 | 移動中、標高変化率 ≥ +0.06m/s            |
| 滑走 | 水平速度 ≥ 1.5m/s、標高変化率 ≤ −0.06m/s |
| 不明 | 上記以外、または時刻／標高の根拠が不足   |

- **双方向ヒステリシス**: 滑走中は0.7m/s（停止境界）まで減速しても標高変化率が+0.025m/s未満なら滑走を維持し、上昇中も−0.025m/s超なら上昇を維持します。標高変化率が通常の上昇・滑走しきい値を満たさない辺での維持は合計15秒までです。停止からの再開時は、直前の移動状態に応じて滑走なら0m/s未満・上昇なら0m/s超で継続判定を行い、停止明けの低速再加速による分断を防ぎます。
- **短時間ノイズ抑止**: 同じ状態（滑走または上昇）に挟まれた15秒未満の反転、および時刻・標高が揃った15秒未満の不明区間を周囲の状態へ統合します。滑走中に20m超の上昇、上昇中に8m以上の下降がある反転は保持します。
- 停止判定は標高なしでも可能です。移動中の標高欠損は不明。リフトと徒歩、スキーとスノーボードは区別できません。

## リフト乗車（有意な上昇区間）の判定

連続した上昇辺をまとめ、リフト乗車中の一時停止（75秒以内）や不明と判定された平坦部（45秒以内）を挟む場合は1回の上昇区間として結合します。時刻・標高の欠損がある辺は実測上昇を分割します。次の条件をすべて満たす区間をリフト乗車（推定、`lifts`）として採用します。

- 上昇状態の合計時間 ≥ 40秒
- 停止を除く水平移動距離 ≥ 60m
- 純上昇量（終了標高 − 開始標高） ≥ 25m
- 停止を除く平均水平速度 ≤ 15m/s（54km/h）、純上昇量 ÷ 停止を除く時間 ≤ 5m/s

### GPS欠損区間をまたぐリフト推定

ゴンドラ内などでGPS受信が120秒超途切れた同一セグメントの空白（120秒超〜1,200秒以内）について、以下の誤検出防止条件をすべて満たす場合のみ、リフト乗車回数として推定計上します（`inferredFromGap: true`）。前後の実測・推定上昇区間との間が75秒以内で、実測が連続し、下り判定や8m以上の下りを挟まず、統合後の純上昇量が25m以上なら1回に統合します。欠損の経過時間は実測上昇時間に含めません。

- 空白の両端に実測標高があり、前後の代表標高（各側15秒以内の最大3点中央値）の差が25m以上
- 直線水平距離 ≥ 60m（静止時の気圧／GPS高度ドリフトを除外）
- 平均水平速度が 0.7〜15m/s（静止ドリフト・高速車両移動を除外）
- 平均上昇速度が 0.06〜5.0m/s（緩慢なドリフト・急激な高度飛びを除外）

**GPS欠損から推定した区間の距離・速度・累積標高差は全体統計へ一切加算しません。**

## 滑走区間と集計の整合性

連続した滑走辺をまとめ、同一連続ブロック内で次の境界が来るまで1本の滑走として統合します。

- 確定したリフト乗車区間（`liftId != null`）
- 180秒（3分）を超える連続した非滑走（途中停止・平坦連絡路など。180秒以内は同一滑走）
- リフト認定未満でも20mを超える登り返し
- 120秒超の記録空白、時刻欠損、セグメント切断、異常ジャンプ

途中に含まれる停止辺・不明辺はそれぞれの状態のまま保持し、滑走時間・滑走距離には加算しません。
滑走辺の合計20秒以上、水平80m以上、下降8m以上（連続する滑走辺ごとにデッドバンド累積下降と純下降の大きい方を集計）を満たす区間を1本とします。満たさない滑走候補は不明へ戻し、全体だけに滑走距離が残ることを防ぎます。

- 全体の滑走距離・滑走時間は、採用した滑走別の値の厳密な合計。
- 平均滑走速度 = 全滑走距離 / 全滑走時間。各滑走の速度の単純平均ではありません。
- 滑走の開始〜終了は180秒以内の停止を含みます。表の滑走時間・下降量は滑走辺を対象とします。
- リフト回数（推定）は採用した上昇区間（`lifts`）の件数と一致します。
- 総移動距離、累積上昇／下降、最高速度、標高範囲は検証済み実測移動のみが対象です。
- 判定不能な時間には同一セグメント内の大きな記録空白を含みます。異なるセグメント間の時間は加算しません。時刻欠損部分の長さは推測しません。

## 描画と処理量

解析はWeb Workerで実行し、再インポート時は前の処理を中断します。解析自体は全地点を使用します。
地図はCanvas描画で実測GPX点列を頂点間の直線（`smoothFactor = 0`）で結び、GPS欠損・非接続区間は薄い破線の補助直線で実測区間と明確に区別します。
グラフは標高（時間×標高）を上段、速度を下段に配置し、約1,600点を目安に間引きつつ状態境界・滑走境界・リフト境界・標高極値・切断を優先保持します。実測区間は状態別の実線（境界点共有）で描きます。時刻順に並ぶ非接続の両端は標高グラフで破線の補助線を表示します。速度は実測のみ表示し、時刻欠損や逆転で地点を描けない区間では線を切ります。

時刻がない部分は地図で確認できます。選択地点はグラフ、地図、キーボード操作可能なスライダーで共有します。図の間引きは統計に影響しません。

## 合成サンプル

`public/samples/hakuba-synthetic.gpx` は架空の4本の滑走・3回の上昇、山麓と山頂の休憩、滑走中2回の15秒停止を含みます。座標は白馬付近ですが実在コースを表しません。標高は概ね1,280〜1,840m、5秒間隔。実走行データを同梱していません。

テストの直線斜面では、61地点・5秒間隔・緯度0.0003度刻み・1点3m下降から、300秒・約2,001.5m・180m下降・平均約24.02km/hの1本を期待します。±2mの平坦ノイズ600区間では累積上下とも0mを期待します。25本連続周回（1Hzノイズ・途中停止・リフト一時停止・重複時刻混在）や180秒停止境界、GPS欠損リフト推定・誤検出防止の期待値は `src/tests/analysis.test.ts` に明記しています。
