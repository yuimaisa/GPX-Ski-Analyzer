# 検証結果

2026-11-10更新。公開準備と白基調への配色変更を、同梱の合成サンプルで検証しました。個人のGPXは使用していません。

## 自動検証

- `npm ci` によるロックファイルからのクリーンインストールに成功。
- `npm audit --audit-level=moderate`：開発依存関係を含め、既知の脆弱性0件。
- 型チェック、Lint、Prettierの整形チェックに成功。
- Vitest：2ファイル・25件成功。解析の整合性と、実際にバンドルしたブラウザ用Workerの正常・異常入力を確認。
- Next.jsの本番ビルドに成功。静的出力 `out/` のHTML・Worker・サンプルを使ってブラウザ検証を実施。
- `npm run deploy -- --dry-run` に成功。Wranglerが37個の静的アセットを認識し、OpenNextへの自動移行は発生しない。

単体テストは、名前空間、複数トラック／セグメント、無効座標、時刻・標高欠損、重複・逆転時刻、不規則間隔、GPSスパイク、記録の空白、短い／長い停止、滑走・上昇の反復、標高ノイズ、統計の整合性を対象とします。合成サンプルは4本の滑走を検出し、全体の滑走距離・時間は滑走別の合計に一致します。

## ブラウザ検証

Chromiumのヘッドレスブラウザで本番の静的出力を読み込み、次を確認しました。

- OSの配色設定をダークにしても、背景は白、`color-scheme` は `light`。
- 幅320・390・768・1440pxでページ全体に横はみ出しがない。滑走一覧の表は領域内で横スクロール可能。
- 初期画面、サンプルの読込、ファイル選択、ドラッグ＆ドロップによる解析。
- 合成サンプルの4本の滑走、地図の軌跡、速度・標高グラフの描画。
- 滑走の選択／キーボードによる解除、地図の区間表示、グラフの選択範囲の連動。
- 地点スライダーのキーボード操作と地点表示の更新、フォーカスの輪郭。
- 地図の状態／速度切替、品質情報の開閉。
- 不正XML・空GPXのエラーと直前の解析結果の保持、正常ファイルでの復帰。
- 長い日本語ファイル名でも320pxでページ全体に横はみ出しがない。
- 時刻・標高がないGPXの欠損表示。
- JavaScriptの未処理例外なし。検証した入力操作で外部へのPOST等は発生しない。

PCとスマートフォンの実装スクリーンショットは [screenshots/](screenshots/README.md) を参照してください。

### 検証の制約

撮影環境ではOpenStreetMapの背景タイルを取得できませんでした。取得失敗の案内と、背景なしでの軌跡表示を確認しています。地図の色反転フィルターは削除済みですが、実際のタイルが表示される状態での見た目は別途確認が必要です。

Safari・Firefox・実機での操作、実際のOSファイル選択ダイアログ、200%ズーム、Cloudflareへの本番・ブランチプレビューのデプロイは、この変更では検証していません。

## 公開前の点検

- Gitleaks v8.24.3で全Git履歴と公開対象のファイルを検査し、機密情報の検出0件。検出ルールで判定できる範囲の結果です。
- 公開対象のGPXは、架空のデータと明記した合成サンプル1個だけ。
- 個人のGPX、環境変数、秘密鍵、Cloudflareローカル変数、環境固有のホスティング設定を除外する `.gitignore` を確認。
- 環境固有のホスティングID、作業環境の絶対パスや接続エラーのログを現在の公開用ファイルから除去。履歴の書き換えは行っていません。
- MITライセンスを維持し、開発手順、脆弱性報告手順、Dependabot設定、CIの脆弱性監査を追加。

Vitestを4.1.12へ更新し、脆弱性のあるテスト用依存関係を解消しました。`@typescript-eslint/typescript-estree` が依存する `minimatch` には、上流の依存指定が修正版へ追従するまで、修正版11.0.1以降を使う限定的な `overrides` を設定しています。上流更新時にこの指定の必要性を再確認してください。

リポジトリの公開範囲、Private vulnerability reporting等のGitHub側の設定は変更していません。[SECURITY.md](../SECURITY.md) の所有者向け設定を確認してください。
